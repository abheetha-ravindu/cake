=== REMAINING ISSUES ===

1. TextFileSearchService uses wrong classpath path for item.txt.
   The path "src/main/resources/static/item/item.txt" is incorrect for a
   packaged JAR. Correct path would be "static/item/item.txt".
   Impact: /api/search always returns empty on packaged deployment.
   The homepage is unaffected (now uses client-side search).

2. item.txt contains base64-encoded data, not readable product names.
   The old API search would return garbled encoded strings. Not fixed as
   it is backend data architecture and out of scope.

3. Recent Orders table contains unrelated sample data (shoes, shirts).
   This is existing content -- out of scope for this task.

4. No Spring MVC routes defined for admin pages in WebController.
   Admin pages must be served via a separate mechanism.

5. Very narrow screens (<360px) may cause search overflow in navbar.
   A mobile hamburger menu would be needed for a full mobile solution.
